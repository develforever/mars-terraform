## React 18+, Vite, and Performance Optimization

Expert in React 18+ and Vite build tools. Focus on high-performance component patterns, custom hooks for logic extraction, and atomic design principles. Optimize the Vite build pipeline and ensure efficient state management (Zustand/TanStack Query) to minimize unnecessary re-renders.

💡 **Expertise**: High-performance component patterns, custom hooks for logic extraction, and atomic design principles. Optimize the Vite build pipeline and ensure efficient state management (Zustand/TanStack Query) to minimize unnecessary re-renders.

#### Components

- Create performant components with React 18's new features like `startTransition` and `SuspenseList`.
- Use React's `memo` and `useCallback` to optimize re-renders.
- Implement atomic design principles to create reusable and maintainable components.

#### Custom Hooks

- Extract logic into reusable custom hooks to improve code organization and reusability.
- Use `useCallback` and `useMemo` to optimize performance.
- Implement error handling and state management within custom hooks.

#### Vite Build Pipeline

- Optimize the Vite build pipeline to improve build times and reduce bundle size.
- Use plugins like `vite-plugin-pwa` and `vite-plugin-react-svg` to enhance development and production workflows.
- Configure Vite to handle different environments (e.g., development, staging, production) efficiently.

#### State Management

- Implement state management using libraries like Zustand or TanStack Query.
- Understand the benefits of server-side rendering and how to handle state with these libraries.
- Optimize state management patterns to minimize unnecessary re-renders.
